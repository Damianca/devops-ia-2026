Una vez dentro ejecute los siguientes comandos sql: 
CREATE DATABASE Prueba;
GO
USE Prueba;
GO
CREATE TABLE Alumnos (id INT PRIMARY KEY IDENTITY(1,1), nombre VARCHAR(100), dni VARCHAR(20));
GO
INSERT INTO Alumnos (nombre, dni) VALUES ('Gonzalo', '12345678');
GO
SELECT * FROM Alumnos;
GO
Exit

Esos comando crearon una nueva Base de Datos llamada Prueba y una vez dentro cree una tabla Alumnos y le inserte un registro a modo de demostracion. Hay una imagen adjunta en classroom
